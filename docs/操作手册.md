# 操作手册

所有命令都在工作空间根目录执行：

```bash
cd ~/workspace/ROS2/robot
```

这台电脑的 `~/.bashrc` 已经加载了 `/opt/ros/jazzy` 和本工作空间的 `install/setup.bash`。新开的终端不用再 source。同一个终端里刚编译完，要执行一次 `source install/setup.bash`，当前终端才会用到新结果。

## 第一次准备

每台电脑做一次。依赖有变化时，把 `rosdep install` 和 `colcon build` 再做一遍。

```bash
cd ~/workspace/ROS2/robot
sudo rosdep init
rosdep update
rosdep install --from-paths src --ignore-src -r -y
colcon build
source install/setup.bash
```

`rosdep init` 若提示 sources list 已存在，说明做过了，跳过这一行即可。`rosdep install` 末尾如果还有 `ERROR`，把缺的包装上再编译。

## 改了机器人模型之后

`robot_gripper.urdf.xacro` 改过，就要重新展开成 `robot_gripper_final.urdf`，再安装这个文件。展开时会用到已经编译好的 `ur_description`、`robot_gripper`、`moveit_robot_setup`，所以前面的第一次编译必须先成功。

```bash
cd ~/workspace/ROS2/robot
source install/setup.bash
xacro src/robot_gripper/urdf/robot_gripper.urdf.xacro -o src/robot_gripper/urdf/robot_gripper_final.urdf
colcon build --packages-select robot_gripper
source install/setup.bash
```

只改了 `robot_move` 里的动作程序时，不用跑 xacro：

```bash
colcon build --packages-select robot_move
source install/setup.bash
```

## 每次运行

开两个终端。先等第一个里的 Gazebo 出现机器人、控制器加载结束，再开第二个。

终端 1：

```bash
cd ~/workspace/ROS2/robot
ros2 launch robot_move gazebo_move.launch.py
```

终端 2：

```bash
cd ~/workspace/ROS2/robot
ros2 launch robot_move run_move.launch.py
```

## 原先那串命令要改的地方

| 原来的写法 | 改成 |
| --- | --- |
| 输出到 `robot_gripper_final.urd` | `robot_gripper_final.urdf`。程序读的是 `.urdf`，写成 `.urd` 时新模型不会被用到 |
| 生成模型后再 `colcon build` 整个工作空间 | `colcon build --packages-select robot_gripper`。只有这个包要把新的 URDF 装进 `install` |
| 编译后 `source ~/.bashrc` | 同一个终端用 `source install/setup.bash`。新终端已由 bashrc 自动加载 |
| 两条 `ros2 launch` 连着敲 | 分成两个终端，先仿真，后动作 |
